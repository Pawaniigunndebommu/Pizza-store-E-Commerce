# Pizza Store E-Commerce Web Application

A responsive front-end e-commerce web application for a pizza store, developed using HTML5, CSS3, JavaScript, and Bootstrap.

## About the Project

This project is designed to provide a simple and user-friendly online pizza ordering experience. Users can browse the available pizza items, add products to a shopping cart, review their selections, and proceed through the checkout interface.

The application focuses on responsive design, interactive functionality, and a consistent user experience across different screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap

## Key Features

- Responsive pizza store interface
- Pizza menu browsing
- Add and manage items in the shopping cart
- Checkout interface
- User authentication interface
- Responsive layout for desktop and mobile devices
- Interactive UI elements

## Getting Started

To run the project locally:

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
